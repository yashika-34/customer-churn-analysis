# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn behavior using the Telco Customer Churn dataset.

The goal is to identify factors influencing customer attrition and generate actionable business insights that can help improve customer retention and reduce churn.

## 📈 Dataset Information

- Total Records: 7,043 Customers
- Features: 21 Columns
- Domain: Telecommunications
- Target Variable: Churn (Yes / No)

---

## 🧹 Data Cleaning

The following preprocessing steps were performed:

- Checked missing values
- Converted TotalCharges from string to numeric
- Handled invalid values using `errors='coerce'`
- Removed rows with missing TotalCharges values
- Verified data quality after cleaning

---

## 📊 Key Findings

### Overall Churn Rate

- Customers Retained: 73.42%
- Customers Churned: 26.58%

**Insight:**
Approximately 1 in every 4 customers leaves the company.

---

### Contract Type Analysis

| Contract Type | Churned Customers |
|--------------|------------------:|
| Month-to-month | 1655 |
| One year | 166 |
| Two year | 48 |

**Insight:**
Customers with month-to-month contracts have significantly higher churn rates compared to long-term contract customers.

---

### Business Insights

- Month-to-month customers are the highest-risk segment.
- Long-term contracts improve retention significantly.
- New customers show a greater tendency to churn.
- Customer tenure strongly impacts retention.
- Customer retention programs should target short-tenure users.

## 🎯 Recommendations

### 1. Encourage Long-Term Contracts

Provide discounts and loyalty benefits for annual and multi-year subscriptions.

### 2. Improve Customer Onboarding

Customers with low tenure are more likely to churn. Strengthen onboarding and engagement efforts.

### 3. Retention Campaigns

Target month-to-month customers with personalized offers.

### 4. Customer Experience Improvement

Improve support quality and proactively engage at-risk customers.

### 5. Monitor High-Risk Segments

Build dashboards to continuously monitor churn indicators.

## 🚀 How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Move into project directory:






Open:

